# Running Tools

Free pacing and fuelling calculators for runners.

Built by [mid40srunningdad](https://instagram.com/mid40srunningdad).

## Tools

- **Pacing calculator** — Negative split race plans with GPS buffer adjustment
- **Fuelling calculator** — Carb and gel timing for half marathon and marathon

## Local development

```bash
npm install
npm run dev
```
